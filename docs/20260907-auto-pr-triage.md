## 教训

- ecosystem 自动发现会把新闻标题当实体名、把新闻日期当 founded。GovTech 那条还是 2020 年的旧闻。管线可以加两道过滤：源日期早于一定时限的直接丢；实体名从正文抽公司或机构名，不照抄标题。
- 模型摘要会混入来源之外的“常识”。自动条目 promote 之前，要拿原文对一遍数字和事实。
